# Preferendus-Agent

An Al-driven design and decision agent equipped with ODESYS-in-FIVES skills, orchestrating IMAP-IGS and TOMAP
capabilities within an integrated design-decision problem-solving environment. Preferendus-Agent comprises two
complementary agents:

- Dialogue Agent: an LLM-based conversational interface through which problem owners and stakeholders
jointly explore, frame, and translate a real-world Problem of Interest (POI) from natural language into an
ODESYS-in-FIVES blueprint. The blueprint includes an initial IMAP-generated best-fit solution and a TOMAP-
based relative ranking and trade-off analysis against other relevant alternatives.
- Delivery Agent: a human-in-the-loop, agentic software-engineering environment built around GitHub, Visual
Studio Code, and GitHub Copilot. It supports experienced ODESYS modellers in extending the blueprint with
Level 1-3 performance models, selecting and configuring the IGS solver best suited to the POI, and developing
the resulting ODESYS-in-FIVES specification into a working prototype, an operational application, and a
scalable design-decision-support solution that delivers actionable results.
